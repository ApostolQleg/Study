# Сутності

- **Аніме:** назва, опис, студія, посилання на вікі, середня тривалість серій, країна, оцінка, статус прокату, теги, рік випуску, вікові обмеження
- **Користувач:** ПІБ, нікнейм, електронна пошта, пароль, аватарка, соцмережі, список аніме, стрік, кастомізаційні опції
- **Коментар:** власник, аніме, оцінка, текст, дата
- **Серія:** нумерація, сезон, належність до аніме, студія, відеоджерело
- **Кімната:** користувачі, плейлист, привілегії, стан плеєра, посилання на приєднання, видимість

# Унікальні ключі

- **Аніме:** id (*UUIDv7*), slug
- **Користувач:** id (*UUIDv7*), nickname
- **Коментар:** id (*Incremental ID*)
- **Серія:** id (*Incremental ID*)
- **Кімната:** *code*

# Припущення

- Поля `mal_id`, `anilist_id`, `hikka_id`, `imdb_id` зберігають ідентифікатори інформаційного контенту про аніме на зовнішніх ресурсах.
    Ми припускаємо, що один запис на зовнішньому ресурсі (наприклад, один тайтл на MyAnimeList) може відповідати декільком записам `anime` в нашій базі даних 
    (наприклад, якщо кілька сезонів одного тайтлу на зовнішньому ресурсі об'єднані в один запис, а в нас представлені як окремі рядки).
    Тому ці поля НЕ можуть бути позначені як `Unique Key` — одне значення зовнішнього ID може повторюватись у кількох рядках `anime`.
- Room не зберігає історію перегляду, а лише поточний стан плеєра та плейлист у межах сесії.
- Користувач, який створить кімнату (room),(`owner_id`) він має бути додатково доданий в  масив `active_users`, щоб в подальшому рахувати, скільки користувачів вже знаходяться в кімнаті.
- Припускаємо, що коли власник кімнати (room) залишає кімнату, то кімната видаляється з бази даних, а всі користувачі, які були в кімнаті, отримують повідомлення про закриття кімнати.
- Оскільки первинним ключем (PK) для таблиці `episode` є `source_url`, ми припускаємо, що кожне відеоджерело є абсолютно унікальним. Одне посилання не може містити одразу кілька серій або бути перевикористаним для іншого сезону/озвучення.
- Припускаємо, що `grade` в таблиці `comment` може бути відсутнім (NULL), якщо користувач залишив лише текстовий коментар без оцінки.
- Головним аспектом конкурентних продуктів є наповненість бази даних, тому базу даних слід регулярно оновлювати.
- Поле `watched_anime_today` є допоміжним для Streaks прапорцем і щодоби скидає своє значення до `false`.
- Якщо аніме існує на зовнішніх ресурсах, але не має українського dub/sub, то воно відображається без плеєрів.
